# Gaaa漫画 (Gamanga)

Windows 桌面漫画阅读器。Kotlin + Compose Multiplatform 写的原生桌面应用，内嵌 Chromium（JCEF）
处理需要登录态与 JavaScript 的页面，其余界面全部原生绘制。

> 本程序是**本地阅读与管理工具**：不提供、不托管、不分发任何漫画内容。
> 所有内容都来自用户自行配置的第三方站点，版权归各自权利人所有。

## 功能

- **书架**：本地书库、分类、阅读进度、已读标记
- **发现**：基于 Bangumi 公开条目数据的推荐墙，可按标签筛选、随机抽、记录想看/在看/看过
- **搜索**：多源并行搜索，结果可跨页保位返回
- **阅读器**：连续条漫 / 分页两种模式，双页、缩放、翻页动画
- **下载**：整部或按章节下载，断点续传，本地阅读不走网络
- **历史**：按最近一天 / 七天筛选，可单条删除或清空
- **备份**：WebDAV 云端备份与本地 zip 备份，可导入 mihon / Tachiyomi 备份
- **隐私**：全部数据留在本机 `%LOCALAPPDATA%\Gamanga\`，不联网上报任何内容

## 使用注意（建议先读）

源站是第三方站点，行为和限制都不由本程序决定。以下几条是实际使用中最容易踩的坑：

- **拷贝漫画**：不要同时刷新多本书，也不要短时间连续下载多部。容易触发临时 IP 封禁，
  表现是长时间转圈或直接失败；等待一段时间通常会自行恢复。
- **MangaBZ**：需要代理才能访问，直连打不开。
- **拷贝漫画 / Komiic**：需要登录。登录态由内置浏览器保持，保存在本机配置目录，换机器不通用。
- **Komiic**：普通用户每天有阅读页数限额，超了要等次日重置。
- 通用：站点随时可能改版、限流、封 IP。遇到问题先看设置里的源站健康状态与日志。

## 两个版本

| | 轻量版 | 完整版 |
|---|---|---|
| 体积 | 约 100 MB | 约 400 MB |
| Chromium 内核 | 不含，首次使用浏览器功能时联网下载（约 370 MB） | 随包附带，解压即用 |
| 只看本地书库 / 已下载内容 | 够用 | 也可以，但没必要 |

安装到含中文的目录也能正常使用：程序会自动把浏览器内核放到纯英文路径下（Windows 上
Chromium 对中文路径支持有问题，这是规避措施，不是 bug）。

## 运行

Windows 10 / 11（x64）。发行包自带 Java 运行时，不需要另外装 JDK。

当前发行 **1.2.1**。解压后双击 `Gamanga/Gamanga.exe`；ZIP 内部根目录固定为 `Gamanga/`，
不带版本号，版本只体现在文件名上。

升级先退出旧程序，不要把旧包的 `app/` 和 `runtime/` 混拷进新包；个人数据在
`%LOCALAPPDATA%\Gamanga\`，不随解压覆盖。

## 从源码构建

需要 JDK 21。

```bash
# 直接运行（开发态）
./gradlew :app:run

# 打绿色版目录 -> build/compose/binaries/main/app/Gamanga
./gradlew :app:createDistributable

# 打 Windows 安装包（需要 WiX Toolset 3.x）
./gradlew :app:packageMsi
```

首次运行会在工作目录下生成 `jcef-bundle/`（Chromium 运行时，约 370 MB），
这是 jcefmaven 自动下载的，不进版本库。

### 测试

```bash
./gradlew :app:desktopTest
```

跑测试前请先退出正在运行的程序：Chromium 内核同一时间只允许一个进程使用，
否则相关测试会卡到超时。

## 数据目录

```
%LOCALAPPDATA%\Gamanga\
├── gamanga.db        书库数据库（SQLite）
├── sources.json      源站地址配置（可手改）
├── downloads\        已下载章节
├── covers\           自定义封面
├── cef-root\         浏览器内核（完整版解压后在此）
├── cef-cache\        内嵌浏览器登录态与缓存
└── logs\             运行日志
```

删掉整个目录等于彻底重置。程序不写注册表，卸载时也不会自动删除这个目录 ——
不再使用时请手动删除。

## 项目结构

```
app/src/desktopMain/kotlin/app/gamanga/desktop/
├── core/       日志、数据库、JCEF 宿主
├── data/       仓库、下载、备份、源站配置
├── source/     各站点适配器、HTTP 客户端
└── ui/         Compose 界面（书架 / 发现 / 详情 / 阅读器 / 设置）
```
